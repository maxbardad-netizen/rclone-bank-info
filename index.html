Workspace Rclone Bank

Частное подключение владельца аккаунта для создания банка документов в Google Диске с помощью rclone. Подключение не предназначено для сторонних пользователей.

Как работает подключение

Выбранные документы копируются из Яндекс Диска в отдельную папку Google Диска. Новые и изменённые исходники обновляют банк. Обратной передачи в Яндекс нет; исчезновение исходника не удаляет сохранённую копию автоматически.

Документы для самостоятельного редактирования хранятся отдельно от обновляемого банка.

Доступ к данным

Разрешения Google позволяют читать Диск и создавать или изменять файлы, доступные этому приложению. Конфигурация rclone определяет папки для фактической обработки; само разрешение Google не ограничено одной папкой.

Передача выполняется через API облачных провайдеров и компьютер владельца. Эта информационная страница не содержит входа в аккаунт, загрузки документов или форм для паролей.
